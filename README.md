# SalesPulse - Sales Analytics Dashboard

A lightweight, high-performance single-page Sales Analytics Dashboard built entirely with vanilla web technologies.

## Highlights
- **Direct Single-Page Dashboard**: Instant executive overview with zero setup or landing page redirection.
- **Pure Vanilla Stack**: Built with vanilla HTML5, CSS3, and modern JavaScript.
- **No CSS Variables**: Handcrafted styling with 100% direct CSS declarations.
- **Offline & Backend-Free**: Leverages browser `localStorage` for instant responsiveness and persistence.
- **Interactive Visualizations**: Dynamic revenue timelines, product category contribution doughnuts, channel performance bars, and ranked product volume leaderboards powered by Chart.js.
- **Complete Transaction Management**:
  - Filter by date range (Today, 7 days, 30 days, 90 days, Year, All time, Custom range).
  - Segment by Category (Software, Hardware, Services, Subscription) and Channel.
  - Multi-column sorting, live search, and pagination.
  - Add, inspect receipts, delete records, reset demo data, and export to CSV.

## Getting Started
Clone or download this repository, then open `index.html` directly in any modern web browser.
